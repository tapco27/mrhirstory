# مستر تاريخ — مهارة Claude لصناعة الريلز

مهارة (Skill) بتخلّي Claude يصنع ريلز «مستر تاريخ» لحساب [@hassan.tabsho](https://www.instagram.com/hassan.tabsho/) بشكلها المعتمد:
مقدمة مستر تاريخ بصوته، بوابة بتفتح والكاميرا بتدخل منها، ثم القصة بصوت المعلّق فوق صور حقيقية بحركة كاميرا،
مع ترجمة ورسوميات متزامنة مع الكلام وموسيقى بتعلى وبتنزل لحالها. الناتج فيديو 1080×1920.

## التثبيت

### Claude Code على الكمبيوتر

بيتثبّت مرة وحدة وبيضل لكل الجلسات على هالجهاز.

macOS / Linux:

```bash
git clone https://github.com/tapco27/mrhirstory ~/.claude/skills/mr-history
```

Windows (PowerShell):

```powershell
git clone https://github.com/tapco27/mrhirstory "$env:USERPROFILE\.claude\skills\mr-history"
```

بعدها افتح جلسة جديدة. للتحديث لاحقاً:

```bash
git -C ~/.claude/skills/mr-history pull
```

### Claude على الويب أو التطبيق

المهارات هون بتنحفظ على الحساب نفسه من ملف `.skill`. افتح جلسة Claude Code على الحساب وابعت:

```text
نزّل https://github.com/tapco27/mrhirstory وشغّل bash pack.sh وابعتلي ملف mr-history.skill
```

واضغط **Save skill** على الملف اللي بيرجعلك. بتضل المهارة على الحساب لكل الجلسات الجاية.

## شو بيلزم كل حساب

| الشي | ملاحظة |
| --- | --- |
| موسيقى السلسلة | مو موجودة بالمستودع لأنها تسجيل لطرف تالت. حط نسختك باسم `template/assets/music/sufi.mp3`. بدونها بيشتغل البناء بموسيقى مولّدة |
| مفتاح ElevenLabs (اختياري) | لتوليد صوت المعلّق من النص. كل حساب بيحفظ مفتاحه. بدونه بتبعت ملف الصوت جاهز |
| موصل Magnific (اختياري) | لتوليد لقطات فيديو. بينربط من إعدادات الموصلات بالحساب |
| على الكمبيوتر | `ffmpeg` و Python 3 و Node.js مع Playwright. جلسات السحابة فيها كل شي جاهز |

## الاستعمال

قول لـ Claude: «ريل مستر تاريخ عن كذا» وابعت النص وكليب مقدمة مستر تاريخ. بيرجعلك مسودة فيديو مع النص المرقّم للتسجيل، وبعد ما يوصل الصوت بيضبط كل شي عليه.

## المحتوى

- `SKILL.md` — تعليمات المهارة.
- `references/` — صيغة ملف الحلقة، الهوية البصرية والصوتية، وربط الإضافات.
- `template/` — القالب مع حلقة «قصة المسجد الأزرق» كمثال كامل بيتبنى كما هو.
